# Contributing to CodexGauge

Contributions are welcome! Open an issue to discuss a bug or idea. To propose a change, fork the repository, make a branch in your fork, and submit a pull request to the main repository with a clear description and how you tested it. The project owner reviews and decides whether to merge each pull request.

Run `python3 build.py --test` before submitting a change. Please avoid including account details, tokens, personal usage data, or third-party assets in contributions.

By submitting a contribution, you agree to license it under the repository’s [MIT License](LICENSE). Please only submit work you have the rights to contribute.
